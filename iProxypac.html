国提供システム等を単位として登録します。「この条件に一致したら、この接続方法を使う」という判定条件を1システムに複数登録でき、 回帰テスト用のURLも複数登録できます。一覧の優先順位は上にあるほど先に判定されます（先に一致したシステムが優先されます）。
「アクセス経路」は proxy.pac が return する値（DIRECT や PROXY host:port）をマスターとして管理します。 ここで登録した「表示名」は、システム登録画面では「接続方法」の選択肢として表示されます。 システム側では実際の値（DIRECT / PROXY host:port など）を個別に書かず、プルダウンから選択します。 複数プロキシのフェイルオーバー（例: PROXY a:8080; PROXY b:8080; DIRECT）も1つの経路として登録できます。
